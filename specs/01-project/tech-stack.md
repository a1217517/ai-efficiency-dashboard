# 技术栈

## 核心框架
- **框架**: Next.js 15 (App Router)
- **语言**: TypeScript 5（严格模式）
- **运行时**: Node.js 20+

## UI/样式
- **CSS 框架**: Tailwind CSS 4
- **组件库**: shadcn/ui
- **动画**: Framer Motion

## 测试
- **单元测试**: Vitest
- **E2E 测试**: Playwright
- **视觉回归**: agent-browser + pixelmatch

## 部署
- **平台**: Vercel（默认）
- **CI/CD**: GitHub Actions

## 工具链
- **包管理器**: pnpm（推荐）或 npm
- **代码格式化**: Prettier
- **代码检查**: ESLint
