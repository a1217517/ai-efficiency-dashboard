# Feature Proposal: AI 效能看板（AI Efficiency Dashboard）

## 1. 目标 (Why)

为团队和项目管理者提供一个可视化的 AI-Native 开发效能看板，直观展示 AI 辅助开发带来的效率提升、代码质量变化和交付速度。通过一个独立的 Demo 产品，验证 v4.0 脚手架从需求到发布的完整工作流是否可行、高效。

## 2. 用户故事 (Who & What)

- **作为** 技术团队负责人，**我希望** 看到团队使用 AI 编码的产出量和质量指标，**以便** 评估 AI 工具的投资回报率。
- **作为** 项目经理，**我希望** 看到各项目的交付周期和阻塞点分布，**以便** 优化资源分配。
- **作为** 开发者，**我希望** 看到个人/团队的编码效率趋势，**以便** 找到提升空间。

## 3. 功能描述 (What)

### 3.1 核心功能（必须在 Demo 中呈现）
1. **核心指标卡（KPI Cards）**：展示 4 个关键指标
   - AI 代码生成量（本周/本月）
   - 测试通过率趋势
   - Bug 发现率（AI 生成代码中的缺陷比例）
   - 平均功能交付时间（从需求到合并的天数）

2. **趋势图表（Trend Charts）**：
   - 代码生成量折线图（按天，支持近 7 天/30 天切换）
   - 测试通过率面积图
   - Bug 分类饼图（按严重程度/模块分布）
   - 团队效能对比柱状图

3. **筛选器（Filters）**：
   - 时间范围：近 7 天 / 近 30 天 / 本季度
   - 团队筛选：全部 / 具体团队
   - 项目筛选：全部 / 具体项目

4. **数据明细表格（Data Table）**：
   - 展示最近 10 条关键事件（代码提交、测试完成、Bug 修复）
   - 支持按时间排序

### 3.2 边界条件
- **空状态**：首次进入时默认加载全部数据，不会出现完全空屏
- **错误状态**：数据加载失败时显示友好的错误提示和重试按钮
- **无匹配数据**：筛选结果为空时显示"无匹配数据"占位图
- **响应式**：支持 desktop（≥1024px）和 tablet（768-1023px），mobile 仅保证可读性
- **数据量极大**：图表使用前端聚合，表格固定展示最近 10 条

### 3.3 非功能要求
- **性能**：首屏加载 ≤ 2s（纯前端静态导出，无真实后端请求）
- **安全**：无敏感数据，无真实 API 调用，所有数据为本地 mock
- **可访问性**：图表添加 aria-label，色彩对比度满足 WCAG AA
- **演示效果**：数据必须"看起来真实"——有波动、有峰值、有不同数量级

## 4. 设计规格 (How - UI)

引用 `design/active.md` 中的默认设计规范（Vercel 风格）：
- 主背景：slate-50
- 卡片背景：white + shadow-sm
- 主色：primary-600 (#2563eb)
- 强调色：emerald-500（正向指标）、rose-500（负向指标）、amber-500（警告指标）
- 字体：系统默认无衬线字体栈
- 圆角：卡片 rounded-xl，按钮 rounded-lg

## 5. 技术规格 (How - Tech)

### 5.1 页面路由
- `/` — 主看板页（Dashboard）

### 5.2 数据模型
所有数据为本地 TypeScript mock 数据：
- `MetricSummary` — 汇总指标
- `DailyTrend` — 日趋势数据
- `TeamComparison` — 团队对比数据
- `EventLog` — 事件日志

### 5.3 状态管理
- 时间范围：`useState<'7d' | '30d' | 'quarter'>`
- 团队/项目筛选：`useState<string>`
- 数据通过纯函数根据筛选条件动态计算（无外部请求）

## 6. 验收标准 (Done)

- [ ] Given 用户打开首页，When 页面加载完成，Then 能看到 4 个 KPI 卡片和 4 个图表
- [ ] Given 用户切换时间范围，When 点击 7天/30天/季度，Then 所有图表和指标在 500ms 内更新
- [ ] Given 用户选择特定团队，When 应用筛选，Then 数据按团队重新聚合展示
- [ ] Given 用户在 tablet 设备访问，When 页面加载，Then 布局自动适配为 2 列
- [ ] 单元测试覆盖率 ≥ 80%（工具函数和组件渲染测试）
- [ ] E2E 测试覆盖：页面加载、筛选切换、图表可见性
- [ ] Lighthouse Performance ≥ 90（静态导出后测试）
- [ ] 成功构建并导出到 `dist/` 目录，可部署到 GitHub Pages
