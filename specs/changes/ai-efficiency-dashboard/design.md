## 3. 组件规范

### KPI Card
- 尺寸：响应式，desktop 4 列，tablet 2 列
- 内边距：p-6
- 圆角：rounded-xl
- 阴影：shadow-sm
- 标题：text-sm font-medium text-slate-500
- 数值：text-3xl font-bold text-slate-900
- 趋势标签：small pill，绿色/红色背景

### Chart Card
- 尺寸：响应式，desktop 2 列，tablet 1 列
- 内边距：p-6
- 圆角：rounded-xl
- 阴影：shadow-sm
- 标题：text-base font-semibold text-slate-800
- 图表高度：h-64 (256px)

### Filter Bar
- 布局：flex, justify-end, gap-3
- 按钮组：白色背景，选中态 primary-600 bg + white text
- 下拉框：白色背景，border-slate-200，rounded-lg

### Data Table
- 表头：bg-slate-50，text-slate-600，text-xs font-medium uppercase
- 行高：h-12
- 交替行：无（保持简洁）
- 状态 badge：small pill，不同颜色

## 4. 响应式策略

- **Desktop (≥1024px)**：KPI 4 列，图表 2 列
- **Tablet (768-1023px)**：KPI 2 列，图表 1 列
- **Mobile (<768px)**：KPI 1 列，图表 1 列，筛选器垂直堆叠

## 5. 空/Error/Loading 状态

### Loading 状态
- KPI 卡片显示骨架屏（3 个 pulse 块）
- 图表区域显示 "Loading..." 居中

### Error 状态
- 全页显示错误卡片：白底，红边框，重试按钮

### 空状态
- 表格无数据时显示 "暂无事件记录" + 图标

## 6. AI Slop 自查

- [x] 圆角统一：xl 用于卡片，lg 用于按钮/输入框
- [x] 阴影统一：全部使用 shadow-sm，无过度悬浮阴影
- [x] 颜色来源：全部来自 Tailwind slate/primary/emerald/rose/amber 调色板
- [x] 字体层级：标题 3xl/1xl/base/sm，层级清晰
- [x] 按钮高度：filter 按钮 h-9，统一尺寸
