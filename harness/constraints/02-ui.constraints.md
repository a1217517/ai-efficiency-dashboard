# UI/UX 规范约束

## 设计系统
- 所有颜色必须从 `design/active.md` 中定义的设计 Token 取值
- 所有间距必须使用 Tailwind 的标准 scale（1 = 0.25rem）
- 禁止在组件中写死颜色值（如 `#ff0000`），必须使用 Token 或 `tailwind.config.ts` 中定义的颜色

## 响应式
- 所有页面/组件必须考虑三种断点：mobile（<640px）、tablet（640-1024px）、desktop（>1024px）
- 禁止在 mobile 断点使用固定宽度布局
- 图片必须提供 `sizes` 属性以优化加载

## 可访问性
- 所有 `img` 必须有有意义的 `alt` 文本
- 所有交互元素（button, a, input）必须有 `aria-label` 或可见的文本标签
- 颜色对比度必须满足 WCAG 2.1 AA 标准（4.5:1）
- 必须支持键盘导航和焦点状态

## 组件状态
- 每个数据展示组件必须处理三种状态：loading、error、empty
- 表单必须显示提交状态和错误反馈
- 异步操作必须提供视觉反馈（按钮 loading、骨架屏等）
