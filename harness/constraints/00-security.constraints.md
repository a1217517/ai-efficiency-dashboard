# 安全边界约束

## 数据安全
- 禁止在客户端代码中硬编码 API 密钥、数据库连接字符串或私钥
- 禁止在日志中输出用户密码、token 或敏感个人信息
- 禁止将未加密的生产数据库备份提交到版本控制

## 网络安全
- 所有外部 API 调用必须通过允许的域名白名单（配置在 `harness/permissions/`）
- 敏感数据传输必须使用 HTTPS
- 用户上传的文件必须进行类型校验和大小限制

## 认证授权
- 每个受保护端点必须显式执行权限检查
- 禁止依赖前端隐藏菜单作为权限控制手段
- Session/Token 必须设置合理的过期时间

## 代码注入防护
- 所有用户输入在渲染到 DOM 前必须经过转义或安全过滤
- 禁止直接使用 `dangerouslySetInnerHTML` 渲染用户输入
- 动态 SQL/查询构建必须参数化
